# Changelog

## v1.3.0 — 2026-10-04

Герой: «мозг» → «Блок».
- Форма живой сети переписана с органической (оболочки Фибоначчи + kNN-волоски + варп) на системную:
  вложенные кубы на одной целочисленной сетке, выращенные из куба-сида внутри чертёжной рамки (уголки,
  шкала делений, пунктирные осевые). Ориентир — ледяные блоки портфолио igloo.inc в нашем языке 1-px линий.
- `lattice.ts` — без случайности в размещении: кольца Чебышёва, линии граней по правилу `full/odd/none`
  («#»-панели), спицы из опорных точек (оси — струты, телесные диагонали — волоски), бусины-кубики на углах,
  тёплые узлы — середины рёбер, пыль — призраки невыстроенных клеток.
- Симуляция: тяга курсора спроецирована на нормаль узла (грань выгибается линзой), смещение зажато
  `maxOffset·a` — сетка остаётся сеткой; рамка дорисовывается по хопам и уходит последней на дайве.
- Рендер: квадратные спрайты узлов, куб-сид с рёбрами в рамке, пунктир осевых (свой буфер дистанций),
  аксонометрия без крена (`tilt [0.5, 0, 0]`, `yaw0 0.65`, оборот или маятник — `orbit.mode`).
- Камера, journey (пин/дайв/нить из ядра), reduced-motion и ярусы — без изменений; N 294/198, E 450/306.

## v1.1.0 — 2026-10-04

Скролл-путешествие «нить из ядра».

- **Пин и дайв героя** (десктоп, fine pointer, герой помещается во вьюпорт): герой запинен на 0.8 vh, скролл
  гонит сцену (камера, доворот, анти-рост, усадка ядра, дрейф ядра к центру) и копию (уезжает и гаснет).
  Мобайл / высокий герой — тот же дайв без пина, скрабом за 0.45 vh. Reduced-motion — ни пина, ни скраба.
- **Нить:** из ядра выходит след, дальше 1-px хребет в левом гаттере каждой секции; кончик всегда на 72 %
  вьюпорта, на стыках секций передаётся бесшовно; в футере уходит горизонтально в пульс-точку.
- **Узлы:** шапки секций получили узел на хребте и рисуемое подчёркивание (вспышка → оседание → линия из
  узла), карточки — квадрат-узел, который зажигает ховер.
- **Хедер по поверхностям:** `[data-surface]` на секциях + ScrollTrigger вместо порога `0.7·vh` — хедер
  прозрачен весь пин и над тёмным Works (убран шов костяной плашки на тёмном).
- **Якоря через Lenis:** клики по `#…` ведёт `lenis.scrollTo` (easing «оседание», фокус на цели), хэш при
  загрузке перепрыгивается после появления спейсера пина (`lenis.resize()` перед прыжком, повтор после
  шрифтов); у цели якоря (секция/main) нет рамки фокуса во всю ширину.
- Ручки: `lib/motion.ts` (`journey`), `config.ts` (`journey.center/shadeOff`), `tokens.css` (`--color-thread*`,
  `--thread-tip-len`, `--node-size`). `ScrollTrigger.config({ ignoreMobileResize: true })` явно.

## v1.0.0 — 2026-06-26

Первая версия сайта **SLK-labs** (студия разработки и автоматизации).

### Что внутри
- Лендинг: `hero` (живая WebGL-сеть) / `works` / `services` / `manifesto` / `contact`.
- **Живая сеть** на three/@react-three-fiber: мягкая пружинная физика — узлы тянутся к курсору,
  «чистая зона» (не слипаются), импульс-волна по клику; в покое монохром, зелёный лишь при
  взаимодействии. `prefers-reduced-motion` → статичная структура.
- **Адаптивный хедер**: прозрачный + светлый на тёмном герое → костяной + тёмный при скролле.
  Якоря не уезжают под фикс-хедер (`scroll-padding-top`).
- Плавный скролл Lenis, ревилы GSAP/ScrollTrigger, кинетический манифест SplitType.
- Дизайн-система: `styles/tokens.css` → Tailwind v4 `@theme` (единый источник правды);
  шрифты Geist/Geist Mono (latin+cyrillic).
- A11y: семантика, skip-link, видимый focus, `reduced-motion` (включая CSS-переходы),
  тап-зоны ~44px; контраст-закон зелёного соблюдён.

### Архитектура
- Контент отделён от логики: `lib/site.ts`, `lib/content/*`, `lib/cases.ts`.
- Живая сеть разнесена: `components/hero/network/{config,shaders,simulation,LivingNetwork}`.
- Карта связей и тюнинга: `CLAUDE.md` (раздел «Карта реализации») + `ARCHITECTURE.md`.

### Стек (заперт)
Next.js 16 (App Router) · TypeScript · Tailwind v4 · GSAP + ScrollTrigger + CustomEase · Lenis ·
SplitType · three + @react-three/fiber + @react-three/drei.

### Дальше (не в v1)
- Фаза 4 — AI-ассистент (`@anthropic-ai/sdk`, серверный route handler).
- Фаза 5 — реальные кейсы, страницы `work/[slug]`, деплой на Vercel (выполняет владелец).
- ⏳ Финальные токены (костяной/зелёный/шрифты) — одной заменой в `styles/tokens.css`.
